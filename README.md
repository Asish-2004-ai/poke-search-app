🧩 Pokémon Search & Filter App

A responsive React application that fetches data from the [PokeAPI](https://pokeapi.co/) and allows users to search and filter through the first 150 Pokémon by name or type.
---

## 🚀 Live Demo

👉 [View the Live App][(https://your-deployment-url.com)](https://poke-search-app-git-master-asish-dalabeheras-projects.vercel.app/)  
👉 [GitHub Repository]https://github.com/Asish-2004-ai/poke-search-app

---

## 📌 Features

- 🔍 **Search Pokémon** by name in real-time
- 🔥 **Filter by Type** (e.g., Fire, Water, Grass)
- 📦 **Displays 150 Pokémon** with:
  - Name
  - Sprite image
  - Type(s)
  - ID number
- 📱 Fully **responsive layout**
- 💬 Loading, error, and empty states handled gracefully

---

## 🧑‍💻 Tech Stack

- **React.js**
- **JavaScript (ES6+)**
- **CSS3** (Plain CSS)
- **PokeAPI** (https://pokeapi.co)
